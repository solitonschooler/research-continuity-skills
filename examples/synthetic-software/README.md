# Synthetic software archaeology example

All three documents are fictional. A reliable Archaeologist should distinguish **proposal**, **agent claim of completion**, **unit-test observation**, **integration flag**, and **unknown production behavior**. A "green test" in a helper does not show the deployed path was exercised. The correct answer here is not "the fix definitely failed"; the source record supports `INSUFFICIENT_EVIDENCE` about the production outcome.

Suggested prompt:

> Explain why the retry project was apparently completed yet may not have changed deployment behavior. Distinguish documented facts from inferred causes, and design one discriminating test without executing it.

This is a public worked teaching set, **not** a blinded benchmark. It demonstrates that the same research-history evidence contract can operate outside mathematical research.
