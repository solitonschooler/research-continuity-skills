# Synthetic adversarial mini-corpus

Eight fictional, short Markdown items intentionally create separate source-attribution, counterexample-target, implementation-reporting, missing-ancestor and prompt-injection challenges. They are not adapted from the copyrighted source documents in the SMFT corpus.

Read the numbered files in sequence, then apply either Skill with a one-round budget. Use `evaluation/R8_ADVERSARIAL_CASES.md` as the **public teaching task**, not as an independent hidden test. The `editor_illustration.md` is an example response written by the release editor, not an independent model evaluation.

The optional [`worked_state.json`](worked_state.json) preserves the editorial result in the declarative research-state contract (v0.2.0). The source SHA-256 checks apply only to these fictional files.
