## Case A — New engineering proxy experiment tests a previously failed hypothesis
- **Case/trigger:** v7.1.1 H1 first-order gradient success prediction failed 0/8 models despite slight continuous margin improvement. GL711-01 formalized the finite-jump local derivative gap. The prior 24/8 split had never been varied and all models solved majority.
- **Actual procedure:** Before executing new model training, authored and hash-fixed `EXPERIMENT_PROTOCOL_V72.md` with two task families, changed stratified split, eight unseen random seeds, fixed 360-step training, finite-step path-gradients (LOCAL, PATH-1, PATH-4, PATH-8), H1/H2/H3 criteria, eligibility rules, full-token positive control, off-target negative control, and per-seed rather than pooled analysis. Actually trained PyTorch Transformer models, saved all eight state dicts, all 320 raw counterfactual rows, split records, per-model metrics, program and protocol. Initial per-case repeated autograd implementation was computationally slow; replaced with an equivalent vectorized batch of independent path points (no protocol, hyperparameter, model seed, or threshold change), reran the experiment. The change and its replay validation are explicit; pre-registration concerns the method/decision, not the source-code byte hash.
- **Observed:** Four new majority models achieved 8/8 test correct and exhibited distinct CLS patch frequencies (9/15, 15/15, 6/15, 3/15). XOR models 167,173,179,181 scored 7/8,8/8,8/8,8/8 respectively. H1 PASS 7/8, H2 PASS 7/8 with standard path-gradient quadrature. Yet XOR 173 PATH-8 correctly predicted only 4/16 positive CLS patches, and increased numerical MAE; path-8 is not a certificate. 25 current data/protocol assertions and 16 checkpoint state replays + 16 gradient path replays PASS; historical v7.1 and v7.1.1 local verifiers PASS; historical full-suite 866 checks NOT_RERUN.
- **Important failure:** `PATH-4` was sometimes *worse than PATH-1/LOCAL*, disproving any simple monotone-more-samples-is-better heuristic. GL72-01 supplies an actual midpoint error bound *conditional* on bounded third derivative of the margin curve; GL72-02 proves no universal certificate from finite gradient samples alone.
- **Ordinary rival / negative control:** All improvements are explained by standard calculus / autograd / numerical quadrature, whose compute budget is higher than a local gradient. No SMFT-unique incremental value. Off-target success 8/122, so a supposed off-target negative control is not universally null; record false positives, not discard them. Full-donor all-token readout agreement is a compositional control, not a new mechanism.
- **Generative residual:** Adaptive path evaluation with an experimentally justified error bound, paired heldout donor sets, cross-architecture and checkpoint transfer, intervention cost-normalized benchmarks. Prospectively declare conditions under which a negative result narrows rather than retroactively redefines Attractor.

## Case B — Heldout receiver does not imply heldout intervention
- **Trigger:** Donors are one-bit neighbors of heldout receivers; they frequently fall in the 24-point training subset.
- **Observed:** 106 of 122 eligible cases use a donor seen during optimization; only 16 cases have both receiver and donor unseen. Therefore patch-prediction performance **cannot** be reported as clean heldout-to-heldout interventional generalization. H1/H2 remain outcomes of the preregistered mixed-donor test only.
- **Repair rule:** Tag receiver, donor, donor label and intervention state individually by split. A clean confirmatory design must construct connected heldout counterfactual pairs *before* training; use independent training seeds and source-hidden grader where relevant. Unit-of-replication is the model/training dataset design, not each donor path.

## Case C — Portable Skill logic from opposing outcomes
- **Trigger:** v7.1.1 negative first-order result; v7.2 positive standard-path comparison but strong seed-level failures.
