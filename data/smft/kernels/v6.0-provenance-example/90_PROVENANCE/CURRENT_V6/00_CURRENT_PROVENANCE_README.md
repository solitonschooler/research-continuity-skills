# v6.0 — Current Provenance Research Kernel (deployment guide)

**Read after `00_READ_ME_FIRST.md`, not instead of K0/K1/K2.** This is a materialized *view* of prior audits. It does not supersede immutable history, and is not a scientific or independent LLM correctness certificate.

## Three deployment modes

1. **RUNTIME_14:** `Project_Upload_Flat/`'s exact 14 files. Fast orientation and broad research continuation. It is the existing official knowledge interface, not independently proven minimal or lossless.
2. **RESEARCH_DEPLOYMENT:** same 14 files plus **four compact current-provenance companions** (this README, `CURRENT_ATLAS_COMPONENT_MATURITY.csv`, `CURRENT_PROOF_AUDIT_INDEX.csv`, `CURRENT_RESIDUAL_AND_NEGATIVE.md`). Add them as optional external reading, not as extra official Project Knowledge slots.
3. **DEEP_PROVENANCE:** load selected `DEEP_*` proof texts, source/lineage/claim/witness tables, and typed edges only when doing rigorous reconstruction or audit. Original PDFs/DOCX/TXT from the 11 source TARs remain available on demand.

## Actual compilation history and count

- 325 source IDs covered in the **v3.7 first bounded pass**. Later source reopening is selectively recorded, not full-document certification. v6.0 performed **no new primary-source deep read**; it verified the existing source identity ledger *against inherited v5.9 bytes*.
- 60 stable Atlas RA IDs. **Only four specified mathematical theorem components (RA-M01..04)** have a previous local model-proof certification. This does not promote the whole cross-domain card, a physical claim or the uniqueness of a discovered natural mechanism.
- 98 distinct **audit** nodes GL50..GL59 (no GL53), L45..L49; they are compiler audit IDs, not 98 externally validated theorems or 98 new historical Witness IDs.
- 400 historical Witness ID slots; 399 already PF-nav-routed in v4.3, W024 intentionally remains an unresolved reserved identifier.
- 83 typed edge records from the later cross-family CSVs. Edges are preserved with original origin and type; they do **not** form an independently proven transitive theorem DAG.
- 619 v3.7 lineage edges and 216 v3.7 claim-gap records retained verbatim in DEEP tables, explicitly marked as inherited historical scope, not as latest independent audit decisions.
- Source-hidden independent LLM reconstruction **NOT_RUN**; no controlled comparison against RAG or neutral summary; private grading/holdout material inside full archive must NOT be exposed.

## Strong claims not authorized by this deployment

- Atlas Maturity `MODEL_THEOREM_COMPONENT_ONLY` is *not* a claim that all claims in that Atlas card are true. A usual pattern is known target order → reverse-engineered map; it does not prove natural P8D genesis.
- Proof Family proximity is a **navigation relation**, not theorem equivalence. Same names or shapes across finance, physical gauge, and agent gating do not imply an isomorphism.
- Source ID with a hash and extracted text is not proof of a full source review. A local math counterexample is not a real-world experiment.
- Publicly sharing FULL releases may expose private benchmark questions, historical test answers or source-internal sensitive content; use the dedicated participant input packages, not the whole audit package.

**Critical data lineage:** `CURRENT_ATLAS_COMPONENT_MATURITY` merges inherited v5.8 and v5.9 status explicitly. The full proof register is **cumulative by concatenation** from 14 original noncumulative math audit files (five L45–49; nine GL50–52 and GL54–59); a simple "take newest file" would silently lose earlier math.

## What the v6.0 compactor itself did *not* do

- It did not reopen and independently verify any of the 325 primary TAR members.
- It did not validate the mathematical correctness of every one of 98 audits or each of 619 historical lineage edges.
- It did not execute an independent source-hidden LLM trial.
- It did not establish that a 14-file runtime collection is truly minimal or optimal under any token budget.

**Operational rule:** when a new result is produced, preserve `SOURCE_ID + physical locator + hash + mathematical hypotheses + counterexample + evidence grade + negative inference + downstream edge + residual`, and update both current views and historical audit provenance. Version counts are not a progress proxy.
