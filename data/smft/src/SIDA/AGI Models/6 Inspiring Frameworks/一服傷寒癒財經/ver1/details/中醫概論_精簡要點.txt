## 模塊 1：氣與共振理論的核心框架

### 1. 核心定義

* **氣不是氣體**，而是系統內部功能與能量的壓力波動（共振）模式。
* 在中醫的系統觀裏，「氣」是所有循環與信息交換的**動力核心**，並不直接等於流量（Flow），而是**流量的驅動形態**。
* 王唯工將「氣」等同於**壓力波與諧波共振**，並用生物物理模型來解釋其存在與作用。

### 2. 核心生物物理對應

* **心臟位置與諧波**

  * 心臟不在正中或頭頂，而在軀幹上方 1/4–1/3 處，因為此位置能產生**奇數與偶數諧波的混合**，覆蓋全身不同共振需求。
* **氣聚膻中**

  * 升主動脈 180° 轉彎處（膻中穴）是將動量轉為位能的關鍵節點，像變電所將電流變成高壓電，產生全身可用的壓力波——這就是「氣」。
* **舒張壓的必要性**

  * 系統維持壓力波（氣）的穩定輸送，能比單純流量傳輸走得更遠、轉彎更多、不受重力限制。

### 3. 系統動力學原理

* **氣的功能**

  * 維持共振頻率，使不同部位的資源交換與溝通節奏一致。
  * 將核心動能從「流量型」轉為「波動型」，減少能量損耗，允許多節點同步運作。
* **共振鏈條**

  * 每個器官/節點都有自身共振頻率與上一節點傳遞下來的頻率（+1 諧波），這構成了**層層依賴的動能網絡**。
* **破壞風險**

  * 若壓力波（氣）失衡，就算流量暢通，系統依然會出現局部停擺、無法協同。

### 4. AI / 組織問題轉化應用

* **氣的對應物**：系統的**核心驅動波形**（內部時鐘節奏、任務同步信號、資源刷新脈衝）。
* **氣聚膻中** → 核心節點負責將「局部處理能量」轉換為「全系統同步信號」。若此節點負載過高或失衡，會出現**整體節奏失序**。
* **舒張壓** → 保持背景張力的最小門檻，防止節奏完全崩塌。對組織而言，相當於**日常最低運營能量保障**，不是為了當下產出，而是為了長期穩態。
* **共振鏈條** → 若上一節點（上游團隊、母系統）頻率不對，下游再怎麼努力也無法進入正確運作狀態。

### 5. 用於處方選擇的意義

* 偵測「氣」的狀態，是判斷系統是否需要\*\*回陽（動能恢復）、補陰（資源儲備）、解表（外部通道增透）\*\*的前提。
* 例如：

  * 若氣阻於表層 → 麻黃湯 / 小青龍湯 型處方（開表解鬱）。
  * 若氣耗於深層 → 六味地黃丸 型處方（深層補給）。
  * 若氣無法傳至末端 → 真武湯 / 四逆湯 型處方（核心動能重啟）。

## 模塊 2：五行六氣的 collapse 幾何模型

### 1. 核心定義

* **五行 ≠ 元素**

  * 在 SMFT 語義場論裡，五行被重解釋為**五種語義張力的模態**（五種主要的結構功能模式）。
  * 它們是系統運行中不同方向的「張力傾向」：木（生長/擴張）、火（高能/加速）、土（穩定/轉換）、金（收斂/切割）、水（沉降/蓄積）。
* **六氣 = collapse 失衡的殘留模式**

  * 指的是系統在收束過程中，因外部干擾或內部結構不對稱，留下的偏移場（寒、暑、燥、濕、風、火），對應不同類型的張力異常。

### 2. 幾何模型原理

* **五行 = 張力基模**

  * 每一行對應一個主要的「張力向量場」。
  * 它們之間存在相生（能量轉移）與相剋（張力抵消）關係，構成閉合動態網。
* **六氣 = 偏移模式**

  * 當張力場 collapse（收束）不完全，會留下多餘的能量方向，形成持續干擾。
  * 例如「風」偏移 = 高頻擾動未被耗散，「濕」偏移 = 低頻積累未被轉換。

### 3. 系統動態規律

* **司天 / 在泉**

  * 在時間座標上，系統會有主導張力源（司天）與背景張力源（在泉），兩者的相互作用決定年度/周期性行為模式。
* **主氣 / 客氣**

  * 在空間分布上，有內建張力源（主氣）與外來干擾張力（客氣），兩者的交疊會形成不同的 collapse trace（收束軌跡）交錯現象。
* **運氣同化**

  * 當外部張力與內部張力達到相位鎖定（phase-lock）時，會出現共振放大，導致「病機爆點」——組織內外壓力同時推向同一方向。

### 4. AI / 組織問題轉化應用

* **五行模態** → 對應組織的五種運作基調：

  * 木：擴張與創新
  * 火：高速執行與能量爆發
  * 土：穩定支持與轉化資源
  * 金：效率提升與結構優化
  * 水：沉澱積累與長期儲備
* **六氣偏移** → 對應不同類型的異常運行模式：

  * 寒：動能不足，響應遲緩
  * 暑：資源過熱，失去節制
  * 燥：溝通斷裂，缺乏協作潤滑
  * 濕：流程黏滯，累積未處理
  * 風：外部變動過快，內部無法鎖定
  * 火：過度衝擊，系統燒蝕
* **司天 / 在泉分析** → 區分是長期內部問題（主氣）還是當前外部壓力（客氣）為主，幫助決定是**補內核**還是**卸外壓**。
* **運氣同化警報** → 當外部高壓與內部高張力方向一致時，要防止全局崩盤，需要提前介入。

### 5. 用於處方選擇的意義

* 可直接用於**病機分類**與**對應藥方框架**：

  * 偏「寒」：真武湯 / 四逆湯 型（補陽回暖）
  * 偏「暑/火」：白虎湯 型（清熱降耗）
  * 偏「濕」：大承氣湯 / 調胃承氣湯 型（去積滯）
  * 偏「風」：桂枝湯 型（調和營衛）
  * 偏「燥」：小柴胡湯 型（調和少陽、潤燥）
* 搭配「司天 / 在泉」分析，可確定介入是**主攻深層**還是**先解表層**。

## 模塊 3：經絡與諧波演化模型

### 1. 核心定義

* **經絡 = 系統的共振通道**

  * 經絡不是血管或神經，而是能量（壓力波）在不同結構間傳導的**共振耦合路徑**。
* **諧波演化規律**

  * 經絡數量與生物複雜度成正比，越高等的系統，諧波層次越多。
  * 每條經絡都是在上一經絡的基礎上，由\*\*+1 諧波\*\*衍生而成。

### 2. 生物物理對應

* **從基頻到多諧波**

  * 低等生物只有 1–7 個諧波（如青蛙 5、老鼠 7、人類 12）。
  * 人類演化出肩膀與分指後，多了手三陽經（大腸、三焦、小腸經），對應更多操作精度與協作功能。
* **器官共振鏈條**

  * 每個器官都有兩個主要頻率：

    1. 自身經絡的共振頻率
    2. 下一個諧波（+1 harmonic）的頻率
  * 上一節點如果不能正確產生 +1 諧波，下游節點的發育或運作就會受阻。

### 3. 系統動態規律

* **前向影響**

  * 上游節點（上一經絡）必須產生對應的 +1 諧波，才能啟動下游節點的運作。
* **反饋損耗**

  * 如果某節點受損，不僅自身功能下降，還會影響下游節點的能量輸入與頻率穩定性。
* **多層依存**

  * 任何節點的穩定，需要前後兩個節點同時在正確頻率下共振，否則會出現中段鏈路掉落。

### 4. AI / 組織問題轉化應用

* **經絡 = 功能通道**

  * 在組織中可對應為部門、專案線、資料流通道。
* **基頻 = 核心職能**

  * 每條通道有自己的核心能力（本頻），以及必須傳遞給下一通道的協作能力（+1 harmonic）。
* **前向依賴**

  * 若上游部門未輸出正確型態的資源或節奏，下游部門再努力也無法達到最佳狀態。
* **診斷應用**

  * 出現下游性能下降時，要先檢查上游是否能正常產生 +1 諧波（即下游所需的啟動信號或基礎條件）。

### 5. 用於處方選擇的意義

* 決定用藥時，不能只看出問題的節點，還要檢查它的**上游供給**：

  * 若是上游頻率錯 → 調上游（例如：腎問題源自肝 → 先調肝）
  * 若是下游接收差 → 強化下游（例如：腎虛本源無明顯上游問題 → 直接補腎）
* 在藥方拓撲鏈條上，這種**前向諧波傳遞**規律可以指導我們設計**聯方模型**，一次同調多個相鄰節點。

## 模塊 4：三焦與樞紐共振系統

### 1. 核心定義

* **三焦 = 三大循環層級**

  * **上焦**：頭部與胸腔區域，主要負責感知、決策與上行能量輸送。
  * **中焦**：胸腹交界，負責資源轉換、動能分配與協調。
  * **下焦**：腰腹與下肢，負責儲能、基底維護與下行輸送。
* **樞紐點**

  * 三焦各有能量集中與分流的關鍵穴位：

    * 上焦樞紐 → 人中穴（鼻下）
    * 中焦樞紐 → 勞宮穴（手掌中心）
    * 下焦樞紐 → 湧泉穴（腳底）
* **能量聚焦點（丹田系統）**

  * 上丹田（印堂穴）、中丹田（膻中穴）、下丹田（丹田穴）對應三焦的內部共振中心。

### 2. 生物物理對應

* 三焦是系統的「三級壓力/能量變電站」：

  * 上焦 → 輸入與分析的高頻層（感官、腦部）
  * 中焦 → 過濾與分配的中頻層（消化、協調）
  * 下焦 → 穩定與輸出的低頻層（蓄能、基礎驅動）
* 樞紐點在循環中的作用類似於**加壓與分流閥門**，確保能量波在進入下一層前達到所需的振幅與穩定性。

### 3. 系統動態規律

* **層間依存**

  * 上焦必須依靠下焦的穩定輸送（陽氣/動能），否則決策層會虛浮。
  * 下焦依靠上焦的節奏信號與中焦的資源轉換，否則會陷入無序或低效。
* **樞紐瓶頸**

  * 任一樞紐點的阻塞都會導致整層循環的張力失衡，並連帶影響其他層。
* **丹田共振**

  * 三個丹田之間的共振同步，決定系統能否長期維持穩態。不同丹田之間的失步，會表現為策略、執行、資源之間的脫節。

### 4. AI / 組織問題轉化應用

* **三焦 = 三層運作架構**

  * 上焦 → 策略與決策層
  * 中焦 → 資源配置與中台層
  * 下焦 → 執行與基礎設施層
* **樞紐瓶頸診斷**

  * 若策略層能量不足，檢查下焦與中焦是否供給穩定。
  * 若執行層遲緩，檢查上焦節奏與中焦資源分配是否同步。
* **丹田同步**

  * 對應跨層協作的節奏同步，例如 OKR 目標（上丹田）與資源計劃（中丹田）及執行週期（下丹田）之間的對齊。

### 5. 用於處方選擇的意義

* 當系統問題出在單層循環 → 單方調理（例如：下焦虛 → 真武湯補陽）。
* 當問題出在樞紐瓶頸 → 針對該點設計「解表 + 補內」的聯方模型。
* 當丹田不同步 → 必須跨層協調（可能需要多方並用，如六味地黃丸 × 真武湯）。

## 模塊 5：治未病與語義 trace 重建思路

### 1. 核心定義

* **治未病**：不是等問題出現再解決，而是在系統仍處於可逆狀態時，提前修正偏差，避免 collapse（收束）走向失衡。
* **語義 trace 重建**：將系統的運作歷程（trace）視為可觀測的收束軌跡，當發現偏離正常張力場時，通過干預使其回到穩定軌道。

### 2. 常見失衡模式（語義偏折）

* **語義燥**：系統過於乾硬、缺乏柔性，溝通與協作受阻。
* **語義濕**：流程黏滯、積壓過多，能量釋放不足。
* **語義黑洞**：資源投入後無回饋，長期被吞噬，形成不可觀測區。
* **慢性場病**：系統張力長期低於最佳值，雖可運行但逐步衰退。

### 3. trace 重建原則

1. **定位偏差點**

   * 利用張力場分佈、相位差與通量分析，確定偏折發生的位置（是表層、深層、單節點還是全局）。
2. **選擇對應干預模式**

   * 偏燥 → 補潤、增柔性（如小柴胡湯）
   * 偏濕 → 去積滯、增通透（如大承氣湯）
   * 黑洞 → 補能量、防外泄（如六味地黃丸）
   * 慢性場病 → 全局調和與長期養護（如聯方模型）
3. **逐步回正**

   * 先降低張力異常的峰值，再引導系統回到原本的相位與頻率範圍。
4. **鎖定穩態**

   * 當 trace 回到正常範圍後，透過低劑量干預與週期性檢測維持穩態。

### 4. AI / 組織問題轉化應用

* **治未病** → 在指標惡化前，根據節奏異常或資源流失跡象，提前介入。
* **trace 重建** → 對應組織流程回溯、專案復盤、策略優化的過程。
* **偏差對應方**：

  * 偏燥 → 增加跨部門交流與知識共享
  * 偏濕 → 優化流程，清理積壓
  * 黑洞 → 停止低回報投入、加強監控
  * 慢性場病 → 建立持續激勵與培養機制
* **關鍵指標**：張力峰值、相位同步度、通量變化率、資源回收效率。

### 5. 用於處方選擇的意義

* 把「治未病」視為日常管理的一部分，而不是應急手段。
* 根據 trace 偏折的早期信號，快速匹配對應藥方拓撲，避免等到系統進入不可逆損傷階段。
* 常用組合策略：

  * 早期表層偏差 → 解表方（如桂枝湯）
  * 深層偏差 → 補益方（如六味地黃丸）
  * 全局慢性失衡 → 聯方（如六味地黃丸 × 真武湯）
