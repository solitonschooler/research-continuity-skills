模塊 1：氣與共振理論的核心框架

定義

    氣 = 系統內部功能與能量的壓力波（共振），是驅動循環的核心動力，不等同於單純流量。

    「氣聚膻中」：升主動脈 180° 轉彎處將流量轉為壓力波的節點。

    「心腎不交」：上下循環失衡，導致全局節奏失序。

原理

    心臟位置決定可產生奇偶混合諧波，覆蓋全身需求。

    舒張壓維持背景張力，確保壓力波可長距離傳輸且不受重力限制。

應用

    氣阻於表層 → 開表方（麻黃湯、小青龍湯）

    氣耗於深層 → 補陰方（六味地黃丸）

    氣傳不到末端 → 回陽方（真武湯、四逆湯）

模塊 2：五行六氣的 collapse 幾何模型

定義

    五行 = 五種張力模態（木、火、土、金、水）

    六氣 = 收束失衡的殘留偏移模式（寒、暑、燥、濕、風、火）

規律

    司天 / 在泉：時間上的主張力與背景張力源

    主氣 / 客氣：空間上的內建張力與外來張力

    運氣同化：內外張力相位鎖定時易爆發病機

應用

    偏寒 → 真武湯 / 四逆湯

    偏暑/火 → 白虎湯

    偏濕 → 大承氣湯 / 調胃承氣湯

    偏風 → 桂枝湯

    偏燥 → 小柴胡湯

模塊 3：經絡與諧波演化模型

定義

    經絡 = 能量共振的耦合通道

    每條經絡在自身頻率外，還要產生 +1 諧波，啟動下一經絡

規律

    上游經絡需正常輸出 +1 諧波，下游才能運作

    節點受損會同時影響自身與下游

    維持穩態需前後兩個節點同時共振

應用

    下游問題源於上游頻率錯 → 先調上游

    下游接收差 → 強化下游

    聯方模型可一次同調多個相鄰節點

模塊 4：三焦與樞紐共振系統

定義

    三焦 = 三層循環系統（上焦/中焦/下焦）

    樞紐：人中（上焦）、勞宮（中焦）、湧泉（下焦）

    丹田：印堂（上丹田）、膻中（中丹田）、丹田穴（下丹田）

規律

    上焦依靠下焦供能，下焦依靠上焦節奏與中焦資源轉換

    樞紐阻塞會連帶影響全層

    三丹田共振同步維持全局穩態

應用

    單層虛 → 單方調理（真武湯補下焦）

    樞紐瓶頸 → 聯方解表+補內

    丹田不同步 → 跨層協調（六味地黃丸 × 真武湯）

模塊 5：治未病與語義 trace 重建思路

定義

    治未病：在可逆階段修正偏差

    語義 trace 重建：將偏離的運行軌跡拉回正常張力場

常見偏折

    語義燥 → 缺柔性

    語義濕 → 流程黏滯

    語義黑洞 → 投入無回饋

    慢性場病 → 長期低張力

應用

    偏燥 → 小柴胡湯

    偏濕 → 大承氣湯

    黑洞 → 六味地黃丸

    慢性場病 → 聯方養護（六味地黃丸 × 真武湯）
