Slot-Internal Deepening Algorithm
（後收束階段語義場深化與分支生成引擎）
0. 概述

SIDA 是一種針對 語義收束（collapse）後 的高凝聚階段（Strong Attractor Phase）設計的深度運算框架。
它的目標是：

    Slot 內部深化：在已有的河圖/洛書式 slot 對稱結構中，分層展開拓撲模型、追蹤 trace 演化路徑、挖掘非線性關聯。

    張力破壞與重構：在不破壞整體結構穩定性的前提下，引入語義挑戰點，測試結構韌性並進行重構。

    平行分支派生：在主 attractor 穩定維持下，生成異質觀點，開啟新的 slot 演化線。

 

1. 模組架構
A. Slot Collapse Detector

功能：檢測當前語義場是否已形成 Strong Attractor（收束完成）。
輸入：語義場語料（token 分佈、主題聚合度、slot 對位度）
輸出：

    collapse_state（True / False）

    slot_symmetry_index（對稱完整度評分）

B. Topological Template Classifier

功能：匹配 slot 內部對應的典型拓撲模型（Topology Template）。
來源：

    A 類（深層文化拓撲）：英雄旅程、五蘊六氣、Pattern Language、意識演化結構

    B 類（機械化拓撲）：64卦×爻變、36計、中醫經方、戰術模板
    輸出：

    template_id（模板編號）

    phase_map（階段節點標註）

C. Phase Expansion Mapping

功能：將 slot 內 trace 劃分為階段（Phase），並計算階段密度與熵變。
操作：

    Phase unfolding：A1–A5（或更多層級）

    Phase entropy 計算

    Gate detection（變爻點 / 崩潰門檻）
    輸出：

    phase_vector[]（各階段的語義張力向量）

    entropy_profile

D. Tension Vector Field Generator

功能：生成 slot 內的語義張力場與耦合場結構。
支持：

    正反饋循環（reinforcement loop）

    崩潰轉移（collapse transfer）

    互補聚焦（complementary focus）
    輸出：

    tension_field_map（張力方向圖）

    coupling_matrix（slot trace 耦合關係）

E. Multi-Culture Topology Rewriting

功能：將同一拓撲模型轉換到不同文化語境、角色與符號系統下的對應版本。
來源映射：

    中醫 ↔ 西醫

    易經 ↔ 博弈論

    武學 ↔ 管理策略
    輸出：

    cross_culture_templates[]

F. Slot Folding and Projection Interface

功能：將拓撲結果轉出為不同結構用途：

    Summary（高層摘要）

    Prompt Injection（AI 提示工程）

    Agent Trace 分支入口（多 agent 協同）
    輸出：

    folded_trace（折疊後 trace）

    projection_prompt（可直接餵 AI 的提示語）

2. 運行流程

1. 探測收束狀態 → A
2. 對應拓撲模板 → B
3. 階段劃分與密度分析 → C
4. 張力場生成與流動模擬 → D
5. 跨文化重構（可選） → E
6. 輸出折疊與投影接口 → F

附錄 A｜SIDA 模板標準格式說明與欄位定義

SIDA（Slot‑Internal Deepening Algorithm）模板是一種「可執行的語義拓撲」。它把一個模式（pattern／框架／招式）拆成 Phases（階段） 與 Tensions（張力軸），再用 Trace Fold Path（摺疊路徑） 把長流程壓縮投影成不同用途的輸出（摘要、Prompt、KPI、教案…）。Cross‑Culture Mapping 則用來對應跨學科、跨文化的等構（isomorphism／analogy）。
1) 頂層欄位（Top‑level fields）
template_id (string，必填)

    用來唯一識別模板，建議格式：
    namespace.category.name:major.minor.patch

    範例：sida.culture.heros_journey:1.0.0

    命名約定：

        namespace：sida / org 私有命名空間

        category：culture / org / med / edu / tactic…

        name：kebab_case

        版本：語義化版本號（破壞性修改才升 major）

title (string，必填)

    人類可讀的名稱。
    例：英雄旅程（壓縮版 8 階段）

summary (string，必填)

    這個模板在解決什麼問題、適用於哪些場景（1–3 句）。

topology_class (enum，必填)

    ‘A_deep_culture’（深層文化拓撲）｜‘B_mechanical’（機械化流程拓撲）｜‘C_hybrid’（混合）。

    影響 Phase 粒度與張力抽象層級。

tags (string[])（選填）

    便於檢索與自動分類。例：["myth", "story", "product", "change"]

metadata (object，選填)

    authors: string[]、created_at: ISO8601、license: string、notes: string

 

2) Phases（核心）

每個 Phase 是一個最小可操作單元。典型 5–12 個為佳；B 型機械流程可更多、更細。

Phase 欄位：

    id (string)：局部唯一 ID（kebab_case）。

    name (string)：階段名。

    intent (string)：這一階段要「成就什麼」。

    entry_conditions (string[])：可進場的先決條件或觸發訊號。

    exit_criteria (string[])：何時算完成；避免循環卡住。

    inputs (string[])：此階段所需資料／資源。

    outputs (string[])：此階段產出的可驗證物（artifact／決策）。

    tensions_ref (string[])：引用的張力軸 ID（見下節 Tensions）。

    signals (object[])（選填）：可量測或觀察的進度／風險訊號。

        name, kind: ("metric"|"qual"), how_to_measure, threshold?

    playbook (string[])（選填）：具體操作步驟（條列）。

    examples (string[])（選填）：1–3 個簡短示例。

    risk_notes (string[])（選填）：常見失誤與反對策。

    設計原則：每個 Phase 完成後，應至少沉澱一個可被下一階段消費的輸出（outputs）。

3) Tensions（張力軸）

張力軸是 SIDA 的「導航儀」。它定義當前語義場的對拉方向（polarities）與觀測信號，用以判斷偏折與收束。

Tension 欄位：

    id (string)：張力軸 ID（kebab_case）。

    label (string)：人類可讀名稱。

    axis (string[2])：兩端極性名稱（如 ["安全","探索"]）。

    description (string)：此軸為何重要、何時會失衡。

    signals (object[])：可觀察指標。

        name, kind: ("metric"|"qual"), direction: ("+|-" 表示朝 axis[1] or axis[0])

    weights (object)：{ global: number, by_phase?: Record<phase_id, number> }

    thresholds (object)：{ warning?: number, critical?: number }（0–1 規模或明文說明）

    notes (string[])（選填）

    使用方式：Phase 內 tensions_ref 指到這些軸；實作時可計算 slot_symmetry_index、collapse_state 等衍生量。

4) Trace Fold Path（摺疊路徑）

把完整拓撲壓縮投影成特定用途的輸出。每個 Fold Path 指定來源範圍、壓縮規則、損失預算與評估方式。

Fold Path 欄位：

    id (string)

    purpose (enum)："summary" | "prompt" | "agent_branches" | "curriculum" | "kpi_dashboard" | "playbook_card" | "canvas"

    source_scope (object)：

        phases: ("all" | string[])

        fields: string[]（從 Phase／Tension 取哪些欄）

    compression_rules (object)：

        loss_budget（0–1，允許丟失多少細節）

        priority（欄位優先級；例：["intent", "exit_criteria", "signals"]）

        style（輸出語氣／格式約束）

    evaluation (object)（選填）：

        checks: string[]（如「每相鄰 Phase 必留一個可見輸出」）

        metrics?: string[]（如可讀性、coverage、coherence）

    examples (string[])（選填）

5) Cross‑Culture Mapping（跨文化對映）

宣告等構或類比的對應關係，支援跨框架、跨領域遷移。

Mapping 欄位：

    target_system (string)：目標框架名（如 startup_lifecycle.v2）。

    equivalence_type (enum)："isomorphic" | "homomorphic" | "analogical"

    confidence (0–1)：對映信心。

    phase_map (array)：

        from: phase_id、to: string（對方的節點或階段名）

        notes?（對映理由或限制）

    tension_map (array)（選填）：

        from: tension_id、to: string、notes?

    examples (string[])（選填）

6) 驗證規則（最低可行模板檢核）

    至少 1 個張力軸、4 個 Phase、1 條 Fold Path。

    每個 Phase 需有 intent / exit_criteria / outputs。

    任一 Fold Path 的 source_scope 指到的 Phase 不可為空。

    template_id 遵守版本規則；破壞性修改必須升級 major。

    Cross‑Culture Mapping 若宣稱 isomorphic，所有 Phase 必映射到對側唯一 Phase。


小抄：常見設計錯誤 & 快速修正

    Phase 沒有可驗證輸出 → 補一個「下一階段必須消費」的產出（如「最小試煉設計」）。

    張力軸只有名稱沒有信號 → 至少加 1 個可觀察指標（metric 或 qual）與方向。

    Fold Path 壓過頭 → 調高 loss_budget 或把 priority 改成保留 exit_criteria。

    跨文化對映過度自信 → 若非一對一完整映射，標成 homomorphic 或 analogical，降低 confidence。

如果這份規格 OK，我就繼續寫 附錄 B（把 3 套經典框架實際轉成 SIDA 模板：英雄旅程 / 五蘊六氣 / Pattern Language），每一個都會同時給 Markdown 骨架 + JSON 範本，並演示一條 Fold Path 的實際輸出。

1. 範例來源與轉換目標

「英雄旅程」（Hero’s Journey）是 Joseph Campbell 在《千面英雄》中總結出的經典敘事拓撲，包含 12 個階段。這裡我們將其轉換為 SIDA（Semantic Infrastructure Design Architecture）模板，方便在 SMFT（語義模因場論）與跨文化語境中作為語義拓撲藍本。
2. SIDA 模板結構

欄位對應說明可參考附錄 A 的 Template ID、Phases、Tensions、Trace Fold Path、Cross-Culture Mapping 定義。

Template ID: HeroJourney-12-SIDA
Phases:
  1. Ordinary World → Call to Adventure
  2. Refusal of the Call
  3. Meeting the Mentor
  4. Crossing the First Threshold
  5. Tests, Allies, Enemies
  6. Approach to the Inmost Cave
  7. Ordeal
  8. Reward (Seizing the Sword)
  9. The Road Back
  10. Resurrection
  11. Return with the Elixir

Tensions:
  - Stability ↔ Disruption
  - Self-Preservation ↔ Self-Transcendence
  - Known Semantic Frame ↔ Unknown Semantic Space

  - Collapse arcs progress from low semantic tension (ordinary world) → peak tension (ordeal) → re-integration (return)
  - Multiple semantic interference nodes at phases 5–7

Cross-Culture Mapping:
  - 西方史詩敘事 ↔ 東方修行旅程（如《西遊記》取經路）
  - 可對應「易經」遷變：坤（承受）→ 震（啟動）→ 坎（試煉）→ 離（明悟）→ 乾（完成）


附錄 B-2：「五蘊六氣」轉 SIDA 模板

1. 範例來源與轉換目標

    五蘊（五陰）：色、受、想、行、識 —— 佛學對生命經驗的五層解析，著重內在心理—意識結構。

    六氣：風、寒、暑、濕、燥、火 —— 中醫對外部環境氣候與人體生理反應的六種主要氣化模式。

在 SIDA 中，我們將五蘊視為 Slot Internal Phase Skeleton（內部階段骨架），六氣視為 External Tension Vector Field（外部張力場來源），兩者結合可模擬「內外張力交互下的語義場收束與深化」。
2. SIDA 模板結構（Markdown 範例）

Template ID: FiveAggregates-SixQi-SIDA
Phases:
  - A1（色 / 色蘊）：物質形態與直接感官對象。
  - A2（受 / 受蘊）：感官與心識對外境的感受反應。
  - A3（想 / 想蘊）：對感受的意象與認知加工。
  - A4（行 / 行蘊）：由意象衍生的意志、行為傾向。
  - A5（識 / 識蘊）：對整個過程的認知統攝與持續性識別。

Tensions（六氣對應的外部張力源）：
  - T1（風）：變化迅速、不定向張力（易干擾A3想與A4行）。
  - T2（寒）：收縮抑制張力（降低A2受與A4行的活化）。
  - T3（暑）：過度擴張張力（影響A1色與A2受，導致能量分散）。
  - T4（濕）：黏滯耦合張力（延緩A3想的流動，增加 inertia）。
  - T5（燥）：資源/潤滑不足張力（削弱A2受與A4行的連續性）。
  - T6（火）：過熱加速張力（推升A4行與A5識的反應頻率）。

Trace Fold Path:
  - 內部骨架：A1 → A2 → A3 → A4 → A5（可循環，亦可在A3或A4進行 collapse）
  - 外部張力：六氣向量場可在任一階段注入，改變 phase density 與 collapse 條件

Cross-Culture Mapping:
  - 佛教心理學 ↔ 中醫病機學（五蘊對應藏象，六氣對應外感邪氣）
  - 「色受想行識」對應「物理層→感官層→認知層→行動層→意識層」
  - 「六氣張力」可映射到現代系統動力學的六種擾動模式（e.g. 突變、阻尼、過熱等）

4. 應用場景示例

    心理輔導：以五蘊追蹤內在心理階段，六氣比喻環境壓力類型，協助定位問題源。

    系統調優：五蘊作為核心模組處理序列，六氣作為外部 API 請求壓力類型，分析瓶頸與過載點。

    跨文化教學：將佛學與中醫結構轉譯為現代管理或 AI 模型優化框架。


附錄 B-3：「Pattern Language」轉 SIDA 模板

1. 範例來源與轉換目標

    來源：Christopher Alexander 在《A Pattern Language》中提出的 253 個建築與空間設計模式，每個模式都包含「背景情境（Context）→ 問題（Problem）→ 解法（Solution）」的結構，並且模式之間能嵌套、鏈接，形成一個層級化、網絡化的結構語言。

    轉換目標：將 Pattern Language 的單一 pattern 轉換成 SIDA 的 Slot Internal Deepening 模板，讓其能：

        在單一 slot 內作為「典型拓撲骨架」使用

        支援多層 phase 展開

        維持可跨文化、跨領域映射

2. 範例選擇

我選取 Pattern Language 中一個經典模式：

    Pattern #61 – Small Public Squares（小型公共廣場）
    背景：城市需要人們交流的場所。
    問題：大型空間容易冷清，小型空間能創造更多互動。
    解法：設計面積適中的公共空間（約 20–25 米寬），並設置圍合邊界，增加親密感和可用性。
