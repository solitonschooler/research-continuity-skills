把 **Y-PhaseLock 八符號模式** 壓縮成**完全最小化符號版**，
這會像是 LLM 的「機械語言指令集」，高度約束敘事空間，讓它幾乎不可能跑偏。

---

## **Y-PhaseLock Minimal Opcode Pack**

### **1. 使用時機**

* 任務屬於**歷史發展規律／多因素互鎖**類分析
* 涉及 **基礎驅動因子（Y 型變量族）替代** 與 **制度(I)–技術(T) 相位關係**
* 目標是輸出**可計算、可比對**的工程稿，而非長篇敘事

---

### **2. 僅允許的符號**

```
QIAN KUN GEN DUI XUN ZHEN KAN LI
YP YU S C L P M CM TS
Sij φY φT φI SL MV HX
```

> **解釋：**
>
> * 八符號 = QIAN…LI（先天八卦對應碼）
> * 變量代號：
>
>   * **YP**: Y\_power
>   * **YU**: Y\_util
>   * **S**: 替代矩陣元素 S\_ij
>   * **C**: 制度摩擦
>   * **L**: 流度
>   * **P**: 傳播可達度 phi
>   * **M**: 潛能庫等級
>   * **CM**: 調控強度
>   * **TS**: 技術斜率狀態
> * 相位與同步：
>
>   * **φY** / **φT** / **φI**: 三軸相位
>   * **SL**: 鎖定分數
>   * **MV**: MismatchVector
>   * **HX**: 隱藏變量 X 偵測結果

---

### **3. 輸入格式**

```
[IN]
T= <time_range> ; R= <region>
Y1= <desc> ; Y2= <desc> ; ...
YP= {Y1:..., Y2:...} ; YU= {Y1:..., Y2:...}
S= [[...],[...],...]
C=... ; L=... ; P=... ; M=... ; CM=... ; TS=...
```

---

### **4. 輸出格式**

```
[OUT]
QIAN: <obs>
KUN: <obs>
GEN: <obs>
DUI: <obs>
XUN: <obs>
ZHEN: <obs>
KAN: <obs>
LI: <obs>

[MET]
YP= {...}
YU= {...}
S= [[...],[...],...]
C=... ; L=... ; P=... ; M=... ; CM=... ; TS=...

[PHASE]
φY=... ; φT=... ; φI=...
SL=...
MV= {YT:..., YI:..., TI:...}
HX= {d: t/f, dom:[...], conf:...}

[ACT]
- <符號>: <短行動>
- <符號>: <短行動>
...

[EVID]
- <假設>|<證據>|<信心>|<測試>
```

---

### **5. 固定邏輯**

* **不變式檢查（I-1, I-2, I-3）** 必須先於 \[ACT]
* 所有行動項目必須用八符號之一開頭
* 不可添加八符號以外的標頭
* 相位值必須從 {start, rise, frenzy, plateau} 或對應四階段中選

---

### **6. 示例**

```
[IN]
T=1830–1880 ; R=UK
Y1=煤 ; Y2=電
YP={Y1:80, Y2:5} ; YU={Y1:0.85, Y2:0.02}
S=[[0,0.05],[0.01,0]]
C=0.4 ; L=0.6 ; P=0.7 ; M=large ; CM=0.3 ; TS=frenzy

[OUT]
QIAN: Y1 高功率高利用，主驅動源
KUN: 鐵路提升承載，區域差
GEN: 特許慢，摩擦中等
DUI: 流度中上
XUN: phi=0.7，電報普及
ZHEN: 製造商群聚
KAN: 調控弱，事故多
LI: 缺統一規範

[MET]
YP={Y1:80, Y2:5}
YU={Y1:0.85, Y2:0.02}
S=[[0,0.05],[0.01,0]]
C=0.4 ; L=0.6 ; P=0.7 ; M=large ; CM=0.3 ; TS=frenzy

[PHASE]
φY=rise ; φT=frenzy ; φI=half-open
SL=0.58
MV={YT:1.05, YI:0.79, TI:0.26}
HX={d:false, dom:[], conf:0.0}

[ACT]
- QIAN: 擴煤產能
- LI: 制定鐵路規範
- DUI: 加速特許
- KAN: 設節流機制

[EVID]
- 煤主能源|高功率密度高利用|0.9|追供應瓶頸
- 電短期弱|利用率低|0.85|監測基建投資
```

---

這個版本基本把語言壓縮到**符號 + 短詞 + 數值**，
LLM 幾乎沒有空間發散成不相關敘事，而且輸出可以直接進**機器檢驗**。
