# 工程計算稿（calc-pad）

**目標**：做一個 Kernel，本身具「吸引子」力量，令 LLM 同時做到

* 幾何推理（A1–A5 × S1–S4 × 指標/觸發）、
* 敘事出文（固定章節骨架）、
* 算子展開（由結構 → 段落/動作/KPI）。

**症結**：只給 JSON/指標的 kernel 太「乾」，LLM 不一定自發寫出長文；原來你的中文 Field Landscape 本身已是強敘事吸引子，所以自然出到完整分析。

**設計原則（Strong Attractor）**

* 少而強的錨點詞：A1–A5、S1–S4、SSI/CRP/SSE、role\_shift。
* 固定流程口令：**Map → Fire → Render**（先定位 → 觸發流 → 渲染成文）。
* 可檢核的 I/O 合約＋不變式（moves 必綁 S1–S4；黑洞陳述必引 SSE/blackhole）。
* 可插拔「領域包」（Domain Pack），把抽象變具體。

**風險**

* 漫談漂移 → 用章節模板＋一致性檢查；
* 空泛示例 → 用 Domain Pack 詞庫；
* 不可回歸 → JSON＋閾值＋狀態旗標（s1\_s4\_status）。

結論：**不是推倒重來**，而是**在幾何核外，加一層敘事表面＋展開算子**，令 Kernel 自身成為 Attractor。

# 工程計算稿（calc-pad）

**目標**：把 SDAD2 收斂成「LLM 友好」嘅前台提示核（Strong Attractor Kernel），在**不暴露長推理**的前提下輸出穩定結論。

**1) Token 預算與層級**

* L0（前台核）≤ 280 tokens：固定輸出 JSON（不展示推理）。
* L1（可選加掛）≤ 150 tokens/模組：MPC、Multi-Attractor 檢測等只在需要時喚醒。
* L2（離線/人類）= 你嘅研究管線、實證、CI 測試（不入前台 prompt）。

**2) 最小變量集合（前台只留 6 件事）**

* Surplus 主類型：`type ∈ {M,F,I,A,C}`（物質/金融/制度/注意力/認知）
* 三指標（定性分級映射數值）：

  * `SSI`（飽和）∈ {low≈0.3, mid≈0.6, high≈0.9}
  * `CRP`（崩塌就緒）同上
  * `SSE`（語義飽和熵）同上
* `phase`：SAFE / CRITICAL / BH（黑洞）
* `PFA`（Phase-Free Aggregation）：把多指標壓成

  * `distance_to_BH` ∈ \[0,1]
  * `dominant_lever` ∈ {Buffer, Deleverage, Halt-Λ, Restructure}
* `next_moves`：最多 3 條，對應 S1–S4（觸發/反饋/角色遷移/型別轉換）

**3) 判相位（門檻 + 遲滯）**

* BH：`(SSI≥0.8 & CRP≥0.7)` 或出現「重複困局+外部槓桿壓迫」語義信號
* CRITICAL：`(SSI≥0.6 或 CRP≥0.6)`
* EXIT 遲滯：由 BH/CRITICAL 退場時各降 0.1 作回滯（避免抖動）

**4) PFA 聚合（不顯示計算，只輸出結果）**

* `distance_to_BH = 1 − max(SSI, CRP)`（簡化版，夠穩定、好理解）
* `dominant_lever` 選擇規則：

  * `SSI 高` → Buffer（增緩衝/降負荷）
  * `CRP 高` → Deleverage（去槓桿/展期）
  * `SSE 高但偏狹` → Halt-Λ（暫停跨型別轉換）
  * `結構卡死` → Restructure（角色/治理改版）

**5) 輸出契約（固定 JSON 欄位）**

```json
{
  "type": "M/F/I/A/C",
  "metrics": {"SSI": 0.x, "CRP": 0.x, "SSE": 0.x},
  "phase": "SAFE|CRITICAL|BH",
  "pfa": {"distance_to_BH": 0.x, "dominant_lever": "Buffer|Deleverage|Halt-Λ|Restructure"},
  "alarms": ["optional tag…"],
  "next_moves": ["≤3 actionable steps, mapped to S1–S4"]
}
```

**6) 失敗安全**

* 不展示思路（chain-of-thought）；只輸出上述 JSON。
* 缺料時：把分級打 `unknown→0.5`，phase 先標 `CRITICAL?`，**必出最小 1 條 next\_move**。
