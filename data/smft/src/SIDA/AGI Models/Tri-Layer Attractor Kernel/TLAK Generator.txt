# 2) Adapter recipe — make ANY framework a TLAK kernel

**Step A — Declare Topology**

* **Anchors (A1..An):** the framework’s stable basins (stages, categories, quadrants).
* **Flows (S1..Sm):** the transitions/forces between anchors.

**Step B — Observables & Thresholds**

* Choose 3–6 *measurable* signals. Define fire-rules for each flow + a black-hole alert.

**Step C — Output Contract**

* Keep the JSON shell (accumulation, thresholds\_used, s1\_s4\_status, triggers, outcome, role\_shift, next\_moves, watchlist, assumptions).

**Step D — Narrative Surface**

* Reuse Sections 0–7 (Exec summary → Stage mapping → S-flows → Role shift → Domain grounding → Risks → 90-day plan → Forecast).

**Step E — Expansion Operators**

* Map each anchor to a 4-tuple paragraph: *Characteristics | Resources | Tensions | Roles*.
* For each fired flow Sx: auto-emit {action, KPI}.
* For black holes: 2 mitigations tied to SSE (or your analog).

**Step F — Consistency Guards**

* Moves’ `lever_on ⊆ {S1..Sm}`; risks citing “black hole” must point to the alert metric; numbers 2 d.p.; unknown → `assumptions`.
