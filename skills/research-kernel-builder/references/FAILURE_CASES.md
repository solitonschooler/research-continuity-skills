# Failure Modes and Countermeasures

The following are auditing patterns, not source-free claims that any particular user corpus contains these mistakes.

| Failure | Why it matters | Minimum response |
| --- | --- | --- |
| Inventory mistaken for full reading | Inflates coverage | Record actual passage/page/document read scope |
| Necessary condition turned into sufficient | Creates fictional source error | Separate source assertion, formalization and stronger tested claim |
| Formula sign/unit/quantifier dropped | Changes theorem | Inspect original equation in context; counterexample or scope check |
| Similar witness merged | Hides different hypotheses | Compare conditions, observer, map, codomain, quantifiers |
| Latest revision treated as complete | Silently loses older proofs | Trace ancestry and deltas; retain valid earlier records |
| Locally fitted target called emergent | Leaks the desired answer | Require target-blind baselines and explicit conditional status |
| Synthetic test called real-world validation | Misleading reliability | Mark synthetic nature and external validity limit |
| Detector alarm without action | Mistaken closed-loop claim | Check intervention path and effects, not only logs |
| Same-source repetition called corroboration | Falsely increases confidence | Track source ancestry and independent evidence |
| Same-session self-rating called blind | Benchmark contamination | Seal scoring answers; use unfamiliar evaluator/test corpus |
| Attractive new explanation recorded as history | Falsified lineage | Separate historical record from rational reconstruction |
| Infinite incremental work | Consumes budget, yields poor handoff | Bounded iterations, improvement receipts, stop rule |

A successful challenge is not proof of the negation of the original claim unless its formal target and quantifiers match. A repaired theorem is an agent contribution unless the source actually contains it.
