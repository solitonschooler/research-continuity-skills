# Changelog

## v0.2.0-draft (2026-10-17) — R8 editorial hardening

- Added normative six-layer acceptance gates, including referential checks that JSON Schema cannot enforce.
- Strengthened conditional schema constraints against phantom source attributions, unperformed-but-passed receipts and checkpoints marked saved with no location.
- Added a synthetic eight-note adversarial mini-corpus, public acceptance matrix and a clearly labelled editor-authored illustration.
- Preserved declarative/no bundled scripts, agent autonomy, bounded iterations and optional research advancement.
- R8 is an editor-side structured rehearsal, not an independent cross-model effectiveness trial.

## 0.1.0-draft — 2026-10-17

- First experimental, English GitHub package with two independent declarative Agent Skills.
- Added common Research Evidence Contract, typed JSON Schema, optional advancement operations, stop/resume rules and independent evaluation design.
- Included only original, clearly synthetic teaching examples; no SMFT FULL archives or original papers.
- No bundled Python/CLI and no selected public license yet.
- This is a **draft for review**, not an externally validated method.
